# Parcours français — Base Bridge

## Angle de lecture
Base Bridge organise le passage Base–Solana ; ce parcours sépare actif, message, preuve et finalisation pour éviter de réduire un bridge à un simple transfert.

## Architecture
Lire les composants Base et Solana, le transport des messages, la vérification des racines et les scripts de déploiement.

## Flux
Un transfert publie une intention, attend une racine actualisée, puis exécute la preuve et la finalisation sur la chaîne opposée.

## Sécurité
Contrôler domaines, signatures, délais, replay, contrats de token enveloppé et clés d’administration.

## Comparaison Bitcoin
Comparer la finalité probabiliste et les preuves interchaînes avec les confirmations et les UTXO Bitcoin.

## Lecture guidée
Commencer par README, configuration, modules Base/Solana puis tests.

## Glossaire
Relayer, racine, preuve, finalisation, wrapped token et message interchaînes.

Parcours documentaire : aucun test ni déploiement exécuté.
